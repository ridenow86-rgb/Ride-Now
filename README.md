# 🚗 Ride Now – Online Car & Bike Rental System

Ride Now is a web-based car and bike rental platform designed to make vehicle renting simple, convenient, and user-friendly.

The project provides separate experiences for users who want to **rent a vehicle** and vehicle owners who want to **list their cars or bikes for rent**.

---

## 🌐 Project

**Project Name:** Ride Now  
**Type:** Online Car & Bike Rental System  
**Technology:** HTML, CSS, JavaScript  
**Repository:** https://github.com/ridenow86-rgb/Ride-Now

---

## ✨ Features

### 👤 Renter Features

- User registration and login
- Create a renter account
- Upload profile information and documents
- Browse available cars and bikes
- Search and filter vehicles
- View vehicle details
- Select cars or bikes based on requirements
- User profile section
- Logout functionality

### 🚘 Vehicle Owner Features

- Owner registration
- Owner profile creation
- Profile photo upload
- Document upload
- Add vehicle details
- Upload vehicle photos
- Set vehicle rental information
- Owner home page
- View listed vehicles
- Owner profile
- Earnings section
